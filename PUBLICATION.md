# Public release contents

This repository includes selected source scripts, geometric inputs, public project instructions, a schematic Soap Tray preview, and reviewed STEP/STL exports.

Personal reference photographs, original conversation and workflow records, local machine paths, workspace rules, editor settings, build logs, screenshots, and unreviewed native Fusion archives are excluded. The source publication begins with fresh Git history; no previous working-folder history is imported.

Export STEP author/organization fields are empty. Build timestamps and timestamp-derived product identifiers have been removed or replaced with neutral identifiers. STL headers are replaced with neutral filenames and units; triangle data is unchanged. STEP geometry and declared units are unchanged. STEP material labels are exporter defaults and do not specify a fabrication material.

The included Soap Tray SVG describes the original scripted geometry. The outdated Solar Charger Case schematic is excluded. Native F3D archives can be generated locally by running the scripts, but are not part of this release because their embedded metadata has not been fully inspected.

This is a targeted review of the exact selected files, not a guarantee that every possible form of identifying information can be detected. Commit author names, email addresses, timestamps, and the hosting account are separate public metadata; configure a public author name and the account's exact GitHub no-reply email before committing.

Generated outputs are excluded until separately reviewed. Do not force-add private files or copy an entire working project into the public repository without review.
